Cyclone 68000 files for the PopSG (Windows CE) build
=====================================================

Cyclone itself is used from the cpu/cyclone submodule
(https://github.com/irixxxx/cyclone68000, commit 3ac7cf1), unmodified.
Its headers (Cyclone.h, tools/idle.h) are included from there. Two files
the build needs are kept here instead:

Cyclone.s
  Generated by Cyclone's own host-side generator from the submodule
  sources, with PicoDrive's cpu/cyclone_config.h and HAVE_ARMv6=0 (this
  device is ARMv5TE; the ARMv6 default would emit sxtb/sxth/uxth). It is
  checked in so the build needs no host C++ compiler. To regenerate it,
  from the repository root, with a native (host) g++:

    cp -r cpu/cyclone /tmp/cyclone-gen
    make -C /tmp/cyclone-gen CONFIG_FILE="$PWD/cpu/cyclone_config.h" HAVE_ARMv6=0
    cp /tmp/cyclone-gen/Cyclone.s CE/cyclone/Cyclone.s

  The checked-in file is byte-for-byte what these commands produce.

idle.s
  A modified copy of the submodule's tools/idle.s (the idle-loop
  detector). See the note at the top of the file for what changed.
