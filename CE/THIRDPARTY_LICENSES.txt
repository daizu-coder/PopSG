PopSG (SHARP Brain PW-G5200 Windows CE port) - Third-party licenses
===================================================================

This build embeds bitmap glyph data derived from the Shinonome font
project for its Japanese/English UI text (CE/ce_shinonome16.h). The
glyph table itself was generated once, on a developer machine, by the
sister PopGB port's sys/ce/tools/shinonome2c.py from the upstream
.bit sources, then copied into this project unchanged - no part of the
conversion tooling or the upstream source tree ships on any device
built from this project, only the resulting glyph bitmaps. This file
should be kept and shipped alongside the binary.

The bitmap font is covered first, below. The emulator itself and its
sub-components - PicoDrive, the Genesis Plus GX parts, the Cyclone 68000
and DrZ80 CPU cores, SVP, the YM2612/YM2413 sound code, the libretro
API header, zlib, and the bundled unzip reader - follow after the font
section, then PopSG's own code (MIT), the menu mascot and app icon
(CC0 1.0), and the Galmuri font.

build (make, CE_FONT=galmuri14) uses glyphs converted from Galmuri14;
the characters Galmuri14 does not have (Greek, Cyrillic and some math
symbols) are filled in from the Shinonome 16dot font described above.

The glyph bitmaps of dist/Galmuri14.bdf (and, for the optional
CE_FONT=galmuri11 build, dist/GalmuriMono11.bdf) were converted by the
sister PopPCE project's CE/tools/galmuri2c.py into the C glyph tables
CE/ce_galmuri14.h and CE/ce_galmuri11.h (a Modified Version under the OFL: format
conversion, character subset, vertical placement, and missing glyphs
filled from Shinonome 16dot). No Reserved Font Name is declared after
the copyright statement in the upstream ofl.md. These glyph tables
remain under the SIL Open Font License 1.1; the rest of PopSG is not
covered by it.
